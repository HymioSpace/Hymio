# 应用 Prompt 与云电脑恢复

状态：Implemented

## 总览

Hymio 提供自己的简短 Markdown system prompt，通过 Oath 的文件注入能力加载。设备恢复归 Backend，模型不负责反复修复基础设施。网页截图明确选择 page_id，桌面截图明确表示整屏，不把两者混为一谈。

`固定角色与风格 → 能力与技能说明 → Oath 能力索引 → 历史和本步输入`

## 指令

应用正文保存在 extensions/prompts/hymio.md，不含用户身份、当前时间、设备绑定、密钥或 memory。启动器明确传入该文件；云端启动使用相同入口。界面能力只简述，用到时读取 hymio-ui skill，不把完整目录和范例重复塞进前缀。

说话简短、如实报告工具结果；失败时只做有依据的有限恢复，不能反复自我重试。不把设备异常当成持续任务，不承诺已经看过仅有链接的截图。Oath 的持久续行上限负责最终阻止无限模型开销。

## 云电脑

每用户一个绑定。确认 missing 才换新环境；paused 恢复原环境；网络和鉴权失败保留绑定，返回明确状态。准备过程串行且有期限；未知副作用不重新执行。单次执行只在派发前恢复暂停环境，不能在执行结果未知时重放命令。

Provider 错误使用有限诊断码，ensure 失败按用户持久退避 5–300 秒。明确创建被拒绝可在退避后重试；创建结果未知只能在旧期限后按设备 metadata 找回唯一原环境，不能凭查询不到就创建。过期 pause/resume 锁仅在 provider 确认目标状态后解除。连接失败发生在业务命令派发前时，记录 failed / dispatched=false 并释放锁。

HTTP ensure 与内部设备列表最多等待准备任务 3 秒；超出返回 preparing，后台仍完成同一个任务。慢速创建不占用整段工具调用 deadline，也不指导模型轮询。连接本身的自动恢复与该过程共用持久用户锁。

网页截图使用 browser screenshot + page_id，返回实际页面、尺寸和受鉴权媒体；computer screenshot 返回桌面原貌。浏览器切换不能激活搜索到的所有 Chrome 窗口。媒体 URL 来自服务端，不接受模型猜测的沙箱文件路径。

Oath 新增的预算暂停/恢复事件进入会话历史；Web/iOS 直接展示暂停说明，发送新消息时清除。应用依赖支持 --system-prompt 的 Oath 版本；这不是 Backend 的模型调用，也不在 Backend 复制 Brain 实现。
