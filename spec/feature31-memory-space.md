# 记忆空间

Status: Implemented (MVP). Extends feature30 without changing Nostalgia's public protocol.

## 产品

Web / Desktop 与 iOS 的入口统一叫「记忆」。默认只有「理解 / 足迹」两个页签、搜索、
收集与星图入口。理解是可追溯的整理，足迹是保留的原始材料。卡片只展示摘要，打开才读完整内容。
不重复引导用户聊天，不以固定大幅角色占据正文。白色/系统表面、墨色正文与少量蓝色强调；
桌面双列卡片、手机单列，详情与星图按需展开。

收集首版支持直接记一笔；使用 saves API 和稳定幂等键，未知结果重试同一正文与键，
成功之后才清空输入。Web 在同一账号页面内保留记忆页状态，切换导航不丢草稿与未确认保存键；
尚未提供退出应用后的持久草稿恢复。保存到足迹不代表已经形成理解。本页不提供整批对话导入入口；
浏览器、文件/图片解析、连接器和自动追踪以后按真实能力开放，不放虚假可用按钮。

## 浏览与星图

两类结果分别分页，文字搜索由 browse 投影调用现有 text/filter search。切换查询淘汰旧请求结果；
不把已加载数量显示成全量，不因某条引用失效而隐藏整张理解。失败、空白、尚未形成理解、
搜索无结果分别呈现。刷新保留可读内容，错误有重试，原文加载失败不以摘要冒充完整证据。

星图只画当前理解到其原始引用的一跳关系，实线代表引用，不根据同主题编造事实关系。
从已加载理解中选择中心；需要时继续分页。小图有等价的依据列表，Web 自适应展示2至6条，iOS 展示前2条并
明确说明，其余仍可在列表打开。零关联保留中心内容。Web 采用 SVG 连线与 DOM 卡片；
iOS 原生卡片与 Path 连线，采用确定性布局。复杂全局聚类、自由力导向、版本比较不在首版。

## 工具与提炼

remember 只选择有跨轮价值的用户事实、偏好、决定、目标或明确要求保留的信息，
不是所有对话都属于 context。新调用必须同时提交 summary（精炼结果，最多2000字符）和
text（支撑它的原话，最多16000字符）。两者原子写进同一原始 record：context.text 保持原文，
context.memory.summary 保存提炼结果，state=proposed 表示尚未发布为稳定理解。
context.provenance 记录 provided_quote 与运行时 invocation_id；这不是已核验的会话消息索引。
目前 ToolInvocation 不提供用户消息 ID，因此首版强制携带原文，不接受模型自报一个无法核验的索引。
客户端足迹详情分别显示原文与提炼草稿。后台提炼必须用原文核对摘要，并引用该原始 record。
直接用户收集不需要模型先做提炼；不能把模型推断、网页、工具输出标记为用户陈述。

recall 默认保留 query 搜索调用兼容；增加 action=read、kind 与 id 精确读取，供模型从
搜索摘要抵达原文。没有读取到完整内容不得用截断 preview 作为完整证据。
记忆结果不能授权外部行动；提炼候选保存成功与正式理解发布分开报告。模型不承诺自动同步、图片识别或
立即更新理解。提炼保留稳定主题身份、具体且短的用户语言主题、真实原始引用和时间冲突。

公开 HTTP 增加 Hymio 产品层 /context/browse；原 search 与 query-only recall 调用继续有效。新 read 参数是可选扩展，
内部读取继续通过现有受认证代理，不暴露服务端凭据。
remember 的新模型 schema 要求 summary + text；旧 text-only 调用明确失败并提示补齐提炼，
不伪造“已提炼”。旧 v1 records 无需迁移，仍按原文展示。运行时已有的工具定义变更保护
会拒绝不匹配的未执行调用，重新部署后使用新 schema；同一 invocation 重试保持幂等。
历史导入 HTTP 路由保留兼容，只有显式调用才写入，不在记忆页批量采集所有对话。

## 平台与状态

iOS 采用原生 segmented picker、搜索、sheet 与导航详情，支持 Dynamic Type、深浅色及
44pt 操作区域；图节点不依赖颜色区分，列表提供 VoiceOver 替代。Web 有键盘焦点、dialog
关闭与详情返回路径；窄屏单列。减少动态效果时不添加非必要运动。

尚无持久离线记忆缓存时，网络失败明确显示暂时读不到，不暗示本地持久缓存已存在。
在当前页面刷新失败时保留之前加载的内容并标注未刷新。真正空态只能在读取成功后出现。

## 选定稿还原：分类与卡片

理解和足迹共用「全部 / 工作 / 学习 / 生活 / 未分类」筛选。分类是内容元信息，不是来源；
旧内容没有可靠分类时进入未分类，不用前端关键词猜测。remember 可提交 category 与简短 title；
直接收集由用户选择分类；提炼在 fields.category/title 发布，topics 仍保留具体主题。
Hymio 增加受认证 /context/browse 产品投影，在服务端读取真实元信息并筛选，独立于
Nostalgia 的 artifact-only topic 过滤。游标保留上游页和页内位置，有限扫描后可继续读取，
不把首页30条的本地过滤伪装成全量分类。读取失败不能归为未分类。
卡片优先使用真实标题，旧数据以原文首句缩略回退；正文与依据不被覆盖。

投影每页最多30条、每次最多扫描4个上游页，6路读取真实元信息。稀疏分类可能需要继续读取；游标绑定分类和关键词。MVP不建立第二套记忆数据库，代价是每次列表增加元信息读取；规模扩大后应在正式协议提供分类索引。历史没有可靠分类的材料不回填猜测结果。
