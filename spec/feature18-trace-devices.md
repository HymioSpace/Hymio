# Trace 阅读与设备可用性

状态：Implemented

## 目标

Trace 按一次回复展示输入消息、模型调用、首包/首正文、输出与 token/cache 用量；聊天主体保持不变。
每个用户每类渠道仅一个活动连接（Web、iPhone、Mac 各一个），云电脑仅一个有效绑定。
云电脑超时暂停后自动恢复；主动暂停保持暂停，Agent 明确请求设备时才唤醒。

## 渠道

绑定按 user_id + kind 唯一，迁移时保留最近活跃记录并撤销重复项。
WebSocket 首帧由 Hymio 校验应用凭证，并认领带过期时间的渠道连接租约。新连接接管，旧连接收到专用关闭码后停止自动重连；不使用 Oath 的投递 cursor 充当产品连接锁。租约由 SQLite 原子更新、定时续期，退出只释放自己的 owner，支持多个后端实例。
客户端声明 channel_kind，缺省为 web；iOS/Mac 显式声明。Oath 保持通用。

## 云电脑

恢复入口集中在 ensure_available。区分已删除、供应商暂不可用、自动暂停、主动暂停和执行结果未知。已删除才新建；暂停连接原环境；结果未知不重放命令。恢复后再次检查物理状态，不能把请求已发送当成恢复成功。

## Trace

每次模型调用单独展示消息数量、输入/输出预览、工具数量和性能指标；原始 JSON 保留折叠入口。未知用量显示未上报，不用零替代。TTFT 是首增量（含思考），首正文单独标记，避免混淆。正文和消息按结构展示，不要求用户先理解 span JSON。

执行锁过期后不能仅凭时间解锁：先向云端查询运行中的 controller 进程，确认已空闲，再按原 invocation_id + deadline 条件释放锁。原操作保留 outcome_unknown，禁止重放；新命令在云端入口再次检查绝对截止时间，避免迟到请求在恢复后执行。供应商查询失败或操作仍运行时继续保留锁。

## 对话布局

助手正文、思考与工具记录统一一列，不逐条重复头像。海獭只出现在顶部工作状态旁，空闲隐藏；账号使用更多入口。Web/Desktop 与 iOS 一致。

## 接入兼容

agent.attach 增加 Hymio 字段 channel_kind；Web/Desktop/iOS 分别发送 web/mac/ios。Hymio 校验后移除该字段再转发到 Oath；旧客户端缺省归类为 web。旧 iOS 客户端需升级后才能与 Web 分开占用渠道。关闭码 4009 表示已被同渠道新连接接管，客户端保留草稿并停止自动重连，允许用户主动接回。
