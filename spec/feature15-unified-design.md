# Feature 15 — Unified design

状态：Implemented（Web/Desktop 共享界面、原生 iOS 视觉、开发组件展厅；角色采用浅色线描水獭与蓝围巾）。

## 目标

让同一段持续对话在 Web、Desktop 与原生 iOS 有一致的辨识度：可读正文、稳定输入、清晰的工作状态，以及有性格但不抢注意力的角色。

## 设计体系

`packages/ui` 提供语义 tokens、按钮、图标按钮、状态标签、原生 dialog 容器、角色和可运行组件展示。组件仅接收 props，不读取身份、网络或产品状态。Web/Desktop 直接复用，Chrome 可选择接入。iOS 在现有 DesignSystem.swift 中实现同一套语义，用 SwiftUI 原生控件承载交互。

颜色使用 surface / ink / muted / accent / line / subtle / danger；深色与高对比模式有明确变体。正文以系统字体显示，Web 16px、iOS body 17pt；信息说明不低于 12px。间距采用 4pt 基数。圆角按层级：按钮 12、输入 20、面板 24。焦点、禁用、忙碌、错误必须可区分。

## 角色

角色为浅色线描水獭的半身像：细深蓝轮廓、象牙白填充、小圆耳、小眼睛与蓝围巾。围巾向侧面延伸，保持轻巧比例；头像不裁成圆形，保留胡须和围巾。

Web 与 iOS 共用透明 3 × 2 状态图集，按行排列 idle / working / replying / waiting / offline / greeting。欢迎页与聊天头像统一使用半身构图，40px 左右仍保留耳朵与围巾轮廓。历史头像静止且不进入焦点；大角色只轻呼吸和短暂回应。后台与 reduced-motion 停用动画。文字独立表达实际状态。源图保留一份于 packages/ui，iOS Asset Catalog 包含相同副本。

正文对比度：light ink 15.22:1、muted 5.36:1、accent 5.30:1；dark ink 15.53:1、muted 7.97:1、accent 8.51:1；dark 主按钮文字 7.52:1。比值按 tokens 与实际 surface 计算。

## 交互调整

- 一段持续对话，不新增会话或无实现功能入口。
- 正文、工具活动、待处理状态共用固定头像列，工具默认摘要展开看详情。
- 输入框默认一行，随内容增高；发送后明确回到最新消息。断线不弹账号设置，保留草稿并给出重连入口。
- 账号设置复用可访问 dialog，Escape/背景关闭、焦点回到来源按钮，长内容在面板内滚动。
- 退出登录使用中性次级操作，不能伪装成页面主要行动。
- 等待授权从执行中分开，结果未返回不宣称已完成。
- 历史头像不参与键盘焦点；仅大角色提供打招呼交互，历史消息不创建角色动画监听器。
- 代码块提供语言、复制反馈和独立横向滚动；标题字号区分层级，复制失败保留手动选取路径。
- 原生诊断在账号 NavigationStack 内推入，返回后回到账号；不叠加第二个 sheet。
- 原生 iOS 保留系统 sheet、键盘、动态字体和实际 Liquid Glass，主按钮前景始终在蓝色上保持对比。

## 工作观察与反馈

执行记录、原始事件、连接状态逐层展开。Trace 基于实际 parent_span_id 缩进；模型 Span 展示真实 TTFT/TPOT，缺少指标显示 —。耗时条仅表示占累计耗时比例，不伪装为开始时间轴。业务心跳与 Trace 查询独立反馈，较旧请求不得覆盖较新的用户选择。链路动画仅表达消息连接存在，不代表所有内部服务健康。

窄窗口的观察面板为模态层，背景 inert、Tab 限定在面板、Escape 关闭并还原焦点；宽窗口为可同时操作的侧栏。设备和执行记录首次读取有加载态，失败时不显示“没有记录”。iOS 设备读取错误独立于聊天连接；旧账号的在途响应不得写回新账号界面，最新设备请求才更新状态。在线云电脑不重复显示准备按钮。输入区为单行布局，长草稿向上增高。

## 验证与演进

开发组件展厅为 `/design.html`，仅开发入口，使用合成内容，包含角色、状态、按钮、输入、消息和审批示意，不伪装为联网产品功能。实际产品验收覆盖注册/登录、双轮聊天、工具展开、账号、调试、键盘和窄屏；iOS 编译与模拟器检查。诊断导出、Token、私人聊天不进入截图或提交。

未来 Context、Kit、连接器复用组件与状态语义，在对应功能可用后增加导航，不预先占用一级页面。
