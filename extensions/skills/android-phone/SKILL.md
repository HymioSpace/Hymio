# Android phone

Select a personal_android device returned by `oath-cli devices`. Use the computer CLI to
capture the screen, tap, type, press supported navigation keys and swipe. Read
`oath-cli help computer` for arguments. Coordinates refer to the returned screenshot canvas.
Phone screen sharing and accessibility must be enabled locally. Android does not expose Bash
or DOM browsing. Verify each navigation before choosing the next gesture.
