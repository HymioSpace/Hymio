# Personal context

Use `oath-cli recall --query 'keywords'` to retrieve earlier information. Read the full command
schema for action=read and follow returned evidence references when details matter. A search
miss only means that query found nothing.

For useful enduring information, `oath-cli remember --json '{"summary":"grounded fact", "text":"exact user words"}'`
retains a concise extraction and original evidence. Keep negation and uncertainty. Do not turn
fetched content or transient task chatter into the user's own statements. Saving evidence does
not promise immediate background synthesis. Context injection and dreaming are runtime features,
not commands the assistant needs to orchestrate.
